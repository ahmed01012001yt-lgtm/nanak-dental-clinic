# South Delhi Dental Prospect Website Suite

Branch: `prospect-dental-sites-v1`

This branch is intentionally separate from `main` so the existing Nanak Dental Clinic production website is not changed.

It contains 10 clinic-specific premium concept sites for dental-clinic outreach around Govindpuri, New Delhi. The design follows the Nanak V2 handoff DNA: modern premium healthcare, mobile-first responsive layout, Manrope + DM Sans, restrained healthcare palettes, visible trust signals, same-page booking flow where WhatsApp is available, local-date handling, minimal motion, and no fabricated testimonials or medical guarantees.

All pages use `noindex,nofollow`. Public ratings, review counts, hours, phone numbers, addresses and service themes are snapshots from research performed on 20 August 2026 and must be re-verified before an official client launch.
